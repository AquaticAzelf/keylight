# Working notes

These are the engineering logs from building Keylight: what was tried, what
was ruled out, and how each part of the keyboard's protocol was pinned down.

They reference scratch artifacts - the official driver's files, captures,
tool outputs - that were used during the work and are **not part of this
repository**. Everything those notes concluded is in
[../../ak820-protocol.md](../ak820-protocol.md) and in the code itself.
